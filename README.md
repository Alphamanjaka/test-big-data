# Mémoire — Plateforme de Centralisation et de Gouvernance des Données Patients

Mémoire de stage (Master 2 — Big Data) portant sur la conception et la réalisation d'une
plateforme de centralisation et de gouvernance de données patients synthétiques :
déduplication multi-sources, Master Patient Index et architecture Big Data.

## Rédaction du mémoire

- `chapters/` : les chapitres du mémoire (squelettes à rédiger) ;
- `documents/cahier_des_charges.pdf` : cahier des charges du stage ;
- `documents/articles/` : articles et supports de lecture ;
- `documents/documentation/` : documentation technique de référence ;
- `references/` : bibliographie et sources citées.

## Code source du projet

Le projet complet (code, données, tests, suivi) se trouve dans
[`projet/code-source/`](projet/code-source/README.md) — dépôt git dont la racine
est ce répertoire `Mon-Memoire/`.

## Organisation du dépôt git

```
Mon-Memoire/
├── documents/           # cahier des charges, articles, documentation       ← documents du stage
├── chapters/            # chapitres du mémoire (01 → 06)                     ← rédaction du mémoire
├── projet/
│   └── code-source/     # code source complet du projet (repo git)           ← implémentation
├── references/          # bibliographie
└── README.md            # ce fichier
```
